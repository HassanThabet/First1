    - **Activities:** Create activity reports (name, date, target group, type, supervisor, participants, interaction rate, teacher/admin cooperation, educational impact, problems, recommendations). Filters by type, date, name. Can view, edit, and create multiple reports. Weekly reports merged for Director. Can delete own reports.
    - **Social Specialist:** Report on student cases (psychological, academic, behavioral counts), actions taken (sessions, family contacts, referrals, follow-ups), guidance programs, challenges, and recommendations. Multiple reports, weekly summary for Director. Can edit and delete own reports.
    - **Educational Supervision:** Teacher performance reports (select teacher/subject, evaluate planning, performance, time management, objectives, strategies, strengths, support needs). Multiple reports, weekly summary for Director. Can edit and delete own reports.
    - **Quality:** Reports on academic performance, educational supervision, discipline/behavior, activities/programs, and social specialist work (positives, observations, proposed actions). Multiple reports, weekly summary for Director. Can edit and delete own reports.
    - **Director:** Views all reports from Vice-Principal, Activities, Quality, Educational Supervision, Social Specialist (with graphs). Views staff specific to their branch (Boys/Girls). Main page for report summaries, actions taken, recommendations. Multiple reports, weekly summary. Can edit and delete own reports.
    - **Chairman:** Views Director's summaries (Boys/Girls). Views all staff reports without exception (Boys/Girls) via dropdown. Graphical and general reports with PDF/Excel export. Also, a page for teacher evaluations (absence, coverage, activity work, administrative supervision) with PDF/Excel export.
    - **Admin:** Views, edits, and deletes all reports. Creates accounts for Director, Vice-Principal, and all members (username/password), specifying branch and supervisor assignments. Manages teacher lists (by subject), classes (with sections and branch), and subjects (add, edit, delete).
